# UI mockups

Static mockups of every surface the app draws, using sample data. The layouts mirror the
SwiftUI views in `SleeperWidgetExtension/` and `SleeperWidget/Views/`.

| File | Shows |
| --- | --- |
| `01-lock-screen-live-activity.png` | Lock Screen with the Live Activity banner beneath a notification |
| `02-dynamic-island.png` | Dynamic Island compact, minimal, and expanded presentations |
| `03-live-activity-states.png` | Banner while leading, trailing, final, and stale |
| `04-lock-screen-widgets.png` | Inline, circular, and rectangular accessory widgets |
| `05-home-screen-widgets.png` | Small and medium Home Screen widgets |
| `06-app-flow.png` | Sign in, league picker, and matchup screen |

`index.html` is the source; open it in any browser to tweak copy, colours, or sample
scores. The PNGs were rendered from it with headless Chromium at 3x.
